# Contribuindo

Commits seguem [Conventional Commits](https://www.conventionalcommits.org/pt-br/): `tipo(escopo): descrição no imperativo`.

## Tipos
`feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`, `build`, `ci`, `perf`, `revert`.

## Escopos
`usuarios`, `aulas`, `atividades`, `provas`, `calendario`, `notificacoes`, `web`, `server`, `docs`.

## Exemplos
- `feat(aulas): adiciona filtro por professor`
- `fix(provas): corrige conflito de horário`
- `docs: atualiza README`

## Ativar a validação

```
git config core.hooksPath .githooks
```
